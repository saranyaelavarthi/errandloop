ERRANDLOOP

Install Python 3.12, then double-click start.bat on Windows or run bash start.sh on macOS/Linux.

The app now starts with Create a group / Join a group / Sign in.
Create your own account, group, actual pickup locations and handover point.
No fictional people or posts are added. Share the group code privately with neighbours.
Each participant signs in separately and posts their own trip and request.
Use another browser or incognito window to test a second account locally.

Keep the terminal open. Stop with Ctrl+C. Local data persists in errandloop-groups.sqlite3.
Optional fictional sample: python -m app.server --demo --open
Public deployment instructions: docs/DEPLOY-AWS.md
